# 데모데이 시연 안내

부스에서 출력한 빗물받이로 입양 → 비 예보 → 점검을 체험시키기 위한 운영 순서입니다.

## 준비물

- 운영자 계정: 서버 DB에서 `role`이 `ADMIN`인 계정. 시연 도구는 `ADMIN`만 쓸 수 있습니다. (`CITY_OFFICIAL`은 제보·사진 검토만 가능)
- 체험용 계정과 폰: 미리 로그인하고 홈 화면에 추가한 뒤 알림을 켜 둡니다.
- 출력한 빗물받이: 한 장이 빗물받이 하나입니다. 한 빗물받이는 한 명만 입양할 수 있으므로 여러 장을 준비합니다.

## 1. 출력한 빗물받이를 지도에 등록하기

1. 운영자 계정으로 로그인하고 지도 탭을 엽니다. 지도 가운데에 빨간 `+`(등록 지점)가 보입니다.
2. 지도를 움직여 등록할 위치를 `+`에 맞춥니다.
3. **새로운 빗물받이**를 누르고, 등록 위치에서 **지도 가운데 지점**을 고릅니다.
4. 출력물을 **낙엽 없이** 찍고 이름을 붙여 등록합니다.

주의할 점

- 등록 사진이 AI에게 '막힘'으로 보이면 그 빗물받이는 입양이 막힙니다. 깨끗한 상태로 찍어 주세요.
- 입양과 점검 사진은 등록한 위치에서 50m 안에서 찍어야 서버가 받습니다. 실내에서는 폰 위치가 틀어질 수 있으니, 행사장에서 폰이 실제로 잡는 위치를 먼저 확인하고 그 자리에 등록하세요.

## 2. 비 내리기

프로필 → **관리자 화면** → **시연 도구** 탭에서 합니다.

| 버튼 | 하는 일 |
| --- | --- |
| 새 체험자에게 비 예보 보내기 | 같은 날짜의 가상 예보를 취소한 뒤 다시 보냅니다. 입양자에게 점검 요청이 가고, 입양하지 않은 사용자에게도 비 소식 알림이 갑니다. 입양자 없는 빗물받이는 대신 점검 대상으로 열립니다 |
| 예보 취소 | 가상 예보와 진행 중인 요청을 취소합니다 |
| 10분 · 30분 켜기 / 끄기 | 지도 배너를 '비 오는 중'으로 바꿉니다. 요청은 만들어지지 않습니다 |

알아 둘 규칙 (서버 설정)

- 같은 날짜에 예보가 이미 있으면 새 요청이 만들어지지 않습니다. 그래서 체험자가 바뀔 때마다 **새 체험자에게 비 예보 보내기**를 다시 눌러야 합니다.
- 가상 예보는 밤에도 바로 보냅니다. 밤 10시부터 아침 8시 사이에는 야간 알림에 동의한 사용자에게만 푸시가 가고, 나머지는 알림 탭에만 쌓입니다.
- 비 시작은 지금부터 3시간 뒤 이후만 됩니다. 기본값인 **내일 오후 3시**를 쓰면 항상 통과합니다.
- 가상 예보는 운영 서버에서 알림을 켠 모든 사용자에게 알림을 보냅니다. 행사가 끝나면 **예보 취소**와 **끄기**를 눌러 주세요.

## 3. 체험이 끝날 때마다

1. 체험 폰에서 빗물받이 상세 → 입양 관리 → **입양 그만두기**로 되돌립니다.
2. 출력물에 낙엽을 다시 올립니다.

## 로컬에서 미리 해 보기

실제 서버 없이 화면 흐름만 볼 때는 개발 서버를 가짜 서버에 연결해 씁니다. 실제 푸시와 AI 판정은 운영 서버에서만 확인할 수 있습니다.
